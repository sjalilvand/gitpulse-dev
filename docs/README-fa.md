# GitPulse AI

**پلتفرم تحلیل و نظارت بر مخازن GitHub با هوش مصنوعی**

GitPulse AI یک پلتفرم کامل و رویدادمحور است که داده‌های مخازن GitHub را دریافت کرده، از طریق Apache Kafka پردازش می‌کند، در PostgreSQL و ClickHouse ذخیره می‌نماید و از طریق یک داشبورد React و Grafana به نمایش می‌گذارد. قابلیت‌های هوش مصنوعی شامل خلاصه هفتگی، تحلیل ریسک PR، دسته‌بندی Issue و یادداشت‌های انتشار خودکار است.

## 🚀 ویژگی‌ها

- **همگام‌سازی بلادرنگ و دوره‌ای** – با Webhook یا زمان‌بند خودکار.
- **معماری رویدادمحور با Kafka** – کامیت‌ها، PRها و Issueها در topicهای اختصاصی جریان دارند.
- **ذخیره‌سازی چندپایگاهی** – PostgreSQL برای داده‌های عملیاتی، ClickHouse برای تحلیل‌های سریع.
- **یکپارچگی با هوش مصنوعی** – خلاصه هفتگی، تحلیل ریسک PR، دسته‌بندی Issue و تولید Release Notes با AvalAI (یا API سازگار با OpenAI).
- **داشبورد مدرن** – React + TypeScript + TailwindCSS با نمودارهای Recharts و نمای چندتبه.
- **داشبوردهای Grafana** – نمودارهای آماده برای فعالیت کامیت‌ها، عملکرد مشارکت‌کنندگان و سلامت سیستم.
- **زمان‌بند خودکار** – همگام‌سازی دوره‌ای با امکان اجرای دستی.
- **CI/CD** – گیت‌هاب اکشنز برای lint و تست.
- **مستندات دو زبانه** – فارسی و انگلیسی برای معماری، نصب و API.
